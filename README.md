Welcome to the official documentation for **UltraEvents**, developed by **GL Studios**.

UltraEvents is an all-in-one automated mini-game event engine designed specifically for modern Minecraft networks and survival servers. It delivers fully automated community party events featuring 15+ built-in mini-games, an integrated in-game arena setup wizard, multi-tier reward engines, and multi-language support.

---

### Key Highlights

* 🚀 **100% Automated**: Start events manually with one click or let the system run automated scheduled events.
* 🎮 **15+ Unique Mini-Games**: From classic TNT-Run and Spleef to modern mechanics like Red Light Green Light, Color Floor, and Moving Walls.
* 🛠️ **Visual Setup Wizard**: Configure your entire arena in 60 seconds with `/eventadmin setup wand`. No manual coordinate editing!
* 🎁 **Universal Economy Integration**: Native support for Vault, PlayerPoints, custom crate keys (ExcellentCrates, CrazyCrates), and custom console commands.
* ⚡ **High Performance & Fork Compatible**: 0% NMS dependencies. Fully compatible with Spigot, Paper, Purpur, and Folia (1.20 - 26.3+).
* 🌍 **Multi-Language Engine**: Full English (`en`) and German (`de`) localization with full MiniMessage & Hex color (`&#RRGGBB`) support.

### Editions

UltraEvents is available in two editions:
1. **UltraEvents Lite**: [Free edition on SpigotMC](https://www.spigotmc.org/resources/ultraevents-lite-automated-mini-game-events-system-1-20-26-3.140244/) featuring 4 community-favorite mini-games.
2. **UltraEvents PRO**: The complete commercial edition with all 15+ mini-games, dynamic custom crates, unlimited commands, and premium support.
